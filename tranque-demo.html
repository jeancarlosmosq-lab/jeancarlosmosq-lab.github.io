Join by scanning

  1. Open JP Dominoes Scorekeeper.
  2. Tap Settings, then the Join Game tab, then Scan QR.
  3. Point the camera at the QR code above. Allow camera access if asked.
  4. The app joins the demo game. Five rounds are already scored, and any round you add is saved to the shared game.

Join without the camera

  1. Tap Settings, then Join Game.
  2. Type DEMO26 in the join code field and tap Join & keep score.

Host a game from the device

  1. Tap Settings, then Join Game, then Host a game.
  2. The app shows a QR code and a 6-character code. Other phones scan or type it to score the same game.

The demo game resets itself once a day, so rounds added by visitors do not accumulate. No account or personal data is involved: the code is the only identifier.
